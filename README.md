# TP Final

A PHP web application built as the final practical assignment of an ENI backend course.

## About The Project

This project is a restaurant review website built from scratch in PHP, organized around an MVC (Model-View-Controller) architecture with a front controller and page templates.

The original assignment (in French) is available in the repository: [Module 07 - Enoncé TP Final.pdf](Module%2007%20-%20Enonc%C3%A9%20TP%20Final.pdf).

### Course

ENI - Le développement Web côté serveur, BackEnd avec PHP et Symfony (Module 7, travaux pratiques)

### Built With

- PHP
